# MAJAKKA — First Light v0.2 QA

**Status:** Local prototype implemented; public real-map and physical Android not independently verified.

## Evidence

- Node.js core tests: **12/12 passed** on local development environment.
- `node --check` for app.js, core.js and sw.js passed.
- Automated Chromium navigation to local HTTP and file URLs was **blocked by the testing environment** (`ERR_BLOCKED_BY_ADMINISTRATOR`). No false claim of a deployed live-page browser test.
- Browser test using Playwright `page.set_content` with **embedded local app JS/CSS** and fallback cartography: mobile 390×844 and desktop 1280×900 both passed; no JS page errors or horizontal overflow, three nodes visible, simulate-visit/attune 3×, pending world pulse, triangular field 1 polygon + 3 lines.
- IndexedDB persistence on actual deployed site, remote vector-tile loading and PWA installation are **NOT TESTED**; persistence is covered at pure `core.js` level only.

## Risks before expanding

- Online basemap needs a real-device and network test. It depends on a remote MapLibre script and an external OpenFreeMap style; offline fallback is intentionally less geographic.
- Hand-authored node coordinates are **demo-only** and must not be used for automatic real-world safe-point creation.
- The field is a **single-player simulation**. Real public fields must never be generated by a single user's isolated movements or private coordinates.
- Cooldowns shown here are local, not anti-cheat; real independent-user enforcement needs a trusted backend and privacy design.
- Spatial interaction is still simulated by a button; natural movement and hardware impact remain unexplored.

**Validated:** locally for source code rules and fallback UI exercise, **not** for production deployment or on-device GPS behavior.

## v0.3.2 — Map readiness repair

- Identified a deterministic script-order race: asynchronous MapLibre loader combined with asynchronous IndexedDB restore could call startMap before the library loaded and miss window.load.
- Switched MapLibre script to defer, added alternate CDN recovery, Fiord→Liberty style timeout and retry control.
- Added mapready handshake to the live GPS session and recenter handler that respects LIVE vs DEMO.
- Manual source inspection: no server-side GPS store added; existing domain and rift rules unchanged.
- **Physical Android, external tile/CDN reachability, and Page load: not independently verified from the build environment.** The user must test on the GitHub Pages URL.
